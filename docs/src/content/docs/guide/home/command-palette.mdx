## Open it

- Press <Kbd>⌘K</Kbd> on macOS or <Kbd>Ctrl</Kbd> <Kbd>K</Kbd> elsewhere. It works on every page, even while you type in a field. Press it again to close.
- Click <Ui>⌘K</Ui> on the rail, or <Ui>Search</Ui> on a not-found page.
- <Kbd>Esc</Kbd>, a click outside or opening a result closes it. The query starts empty each time.

## What it finds

| Group                 | What you get                                                                                                                                          | Shown when                                                  |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| Repositories          | Each repository with its overall health and the areas that need attention. Selected, it previews its groups, forge, health and links to its hub tabs. | you have `repos:read`                                       |
| Libraries and symbols | Packages and libraries, and exported symbols from two characters on.                                                                                  | you can read the catalog and typed a query                  |
| Pages                 | Every page you can open, titled `Workspace › Page`.                                                                                                   | always                                                      |
| Settings              | The same index as the search field on Settings.                                                                                                       | for the Settings sections you can open                      |
| Actions               | Switch theme, open the documentation, start a new chat thread, sign out.                                                                              | always (new thread when Chat is visible)                    |
| People                | People, opening them on Settings › People.                                                                                                            | you have `users:read` and Holtkeeper keeps its own accounts |
| Recent                | Pages you opened from the palette.                                                                                                                    | while you can still reach them                              |

Without a query, the palette shows Recent first, then Pages and Actions.

## Narrow the search

Click a chip to search one kind; it then lists up to 50 matches. Or start the query with a prefix:

| Prefix | Searches     | Example  |
| ------ | ------------ | -------- |
| `>`    | Actions      | `>theme` |
| `#`    | Repositories | `#admin` |
| `@`    | People       | `@mira`  |

Matches rank a title that starts with the query first, then a word of the title that starts with it, then any part of the title, then every word found in the title, subtitle or keywords. Words split on spaces and on `/ . : › @ _ -`, so `kit` finds `@acme/widget-kit`.

## Move with the keyboard

| Key                       | Does                                 |
| ------------------------- | ------------------------------------ |
| <Kbd>↑</Kbd> <Kbd>↓</Kbd> | Move the selection; it wraps around. |
| <Kbd>↵</Kbd>              | Open the selected result.            |
| <Kbd>Esc</Kbd>            | Close the palette.                   |

Results that are pages are real links: <Kbd>⌘</Kbd>-click or a middle click opens them in a new tab.

## Recent items

The palette remembers the last eight pages you opened from it, newest first; actions are never remembered. The list is kept in this browser per person, so people sharing a browser never see each other's items, and signing out clears it. Items you can no longer reach drop out on their own.

:::tip
If a repository link leads to a not-found page, it suggests up to three repositories a few typos away, only from those you can see.
:::
