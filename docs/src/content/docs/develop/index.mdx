## Rules of the repository

- **No build step.** Packages export `./src/index.ts` and Bun runs it directly.
- **Erasable TypeScript only**: no `enum`, `namespace` or parameter properties; `.ts` extensions in imports.
- **Depend on interfaces.** Analyzers talk to `GitForge`, never to a GitLab client; anything that shells out takes a `CommandRunner`, so tests use a fake runner.
- **Tests sit next to the code** as `*.test.ts`; integration tests and fixtures live in the module's `test/` folder.
- **Docs move with code**: a change to a module's behaviour updates its `docs/` in the same change.
- **Made-up examples only** in tests, fixtures and docs.
- `bun run check` runs everything CI runs: format, lint, typecheck, tests and knip.

The full contributor guide is [AGENTS.md](https://github.com/holtkeeper/holtkeeper/blob/main/AGENTS.md) in the repository.
