# Branches

Part of the web app's [Quality](README.md#quality) docs.

**Branches** (`/quality/branches`, `features/branches/`, `analyses:read`) is a read-only `FleetTable` over `GET /api/branches`: one row per branch worth deleting in every readable repository's newest `branches` record. Columns: a checkbox, the branch (a link to it on the forge) with its repository (links to the hub's Quality › Branches), the reason (**Merged**, **Closed MR**, **Stale**), the head commit's author, the last commit's age and date, and the merge request (a link to the forge with its state). Branches with an open merge request are never listed; each repository lists its oldest branches up to a fixed number and the footer counts the ones left out.

The toolbar has the scope switch (_My teams_ folds other teams' branches into one row), a reason switch with counts, **Author** and **Age** (older than 30, 90 or 365 days) filters; the header search matches branch, repository or author. The `Strip` comes from the stored counts of the repositories in scope, not the listed rows: to clean up (in how many repositories), merged, closed merge request, stale (with the threshold when every repository uses the same), branches besides the default with those kept for an open merge request, the change of "to clean up" since each repository's previous run, and the oldest branch. Without a sort rows go oldest first; every column sorts. **Run now** (primary, `analyses:run`) queues the `branches` analyzer and **Configure** opens `analyzers.branches`.

Selecting rows (checkboxes, a click, J/K and ↵, or the header checkbox for every shown row) opens `BranchesSheet`, which has no cleanup action: **Selection** lists the selected branches by repository with links to the forge and **Copy list** (`path branch` per line), **By author** sums branches to clean up per author across the repositories in scope with their oldest age, **Since last run** shows each repository's change of every count against its previous run. **Select merged and closed** and **Clear selection** are its quiet actions; **By author** and **Since last run** in the page's ⋯ menu open it without a selection. The selection lives in the page and is not kept in the URL.

Search parameters (`parseBranchesSearch` in `lib/branches.ts`): `repo`, `q`, `reason`, `author`, `age`, `sort`/`dir` and `panel` (the open sheet panel). The hub's Quality › Branches (`BranchesRepoSection`) is the same table narrowed to the repository. Helpers (`branchListRows`, `filterBranchesExceptReason`, `reasonCounts`, `branchKpis`, `authorTotals`, `branchChanges`, `selectionByRepo`) live in `lib/branches.ts`.
